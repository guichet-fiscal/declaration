        Sauvegarde et restauration
        
          
        Un clic télécharge tout le registre dans un seul fichier : barème, entreprises, déclarations, avis, demandes et décisions. Déposez une copie dans un salon du staff chaque semaine.
        
          
        
            
            
          
        
          
        
            
            
            Les dossiers du fichier remplacent ceux qui portent le même numéro. Les dossiers absents du fichier sont conservés.
            
          
        
        
        
        
        
          
        Accès au guichet
        
          
        Chaque personne se connecte avec son compte Discord. Ajoutez ici son identifiant Discord : dans Discord, Paramètres → Avancés → Mode développeur, puis clic droit sur son profil → Copier l’identifiant.
        
          
        
            
        
            
        
            
        
            
          
        
          
          
          
        
          
        
          
          
          Qui peut faire quoi
          
          
            
            
          • Direction : saisit les dossiers, décide et gère les accès ci-dessus.
            • 
            
          • Lecture seule : consulte le registre et télécharge les sauvegardes. Idéal pour les administrateurs du serveur.
            • 
            
          • Les joueurs n’ont pas besoin d’accès : ils déclarent sur Discord avec les modèles, vous collez leur message ici.
            • 
            
          • Les propriétaires de l’organisation GitHub et du projet Supabase gardent la main sur le code et les données, même sans passer par ce site.
